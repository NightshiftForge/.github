## Welcome to the Nightshift Forge GitHub!

**Nightshift Forge** is an independent fan project aiming
to recreate the original **Need for Speed: Underground
(2003)** from the ground up using **Unreal Engine 5**.

We currently develop the game and plugins privately.
We plan to share reusable Unreal Engine tools with
the community when they are ready.

*This is an unofficial fan project and is not
affiliated with or endorsed by Electronic Arts.*
